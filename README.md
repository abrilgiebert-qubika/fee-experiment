# Transaction fee experiment – prototype
Static, self-contained prototype (no build step, no subfolders). Open `index.html` (it redirects to `Start.dc.html`).
Locally, use a web server: `python3 -m http.server 8000` and visit http://localhost:8000
Deploys as-is on Vercel or GitHub Pages. `support.js` is the runtime the screens need; keep it next to the HTML files.
